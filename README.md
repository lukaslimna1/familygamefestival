# Family Game Festival

> Materiais visuais e referências do Family Game Festival 2026.

## Conteúdo

- `Usar/Cores e Tipografia/` — paleta de cores, elementos gráficos e recomendações tipográficas.
- `Usar/Mascote/PNG/` — seis poses do mascote em PNG.
- `Usar/Mascote/SVG/` — seis poses do mascote em vetor.
- `Usar/Mascote/Mascotes.ai` — arquivo-fonte editável do mascote.
- `Referencias existentes/Base/` — referências visuais, peças anteriores e portfólio do festival.

## Direção visual

A identidade combina uma base escura com acentos vibrantes em amarelo, vermelho, ciano e magenta. O sistema visual usa elementos inspirados em interfaces de videogame, como grid, pixels, controles, estrelas, troféus e barras de energia.

### Tipografia recomendada

- Display: Bebas Neue
- Subtítulos e chamadas: Montserrat SemiBold
- Texto corrido e informações: Inter Regular

## Observação

O conteúdo deste repositório é material de trabalho e deve permanecer privado.
