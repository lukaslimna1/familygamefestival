# Mascotes

Os mascotes oficiais ficam nesta pasta em SVG para manter nitidez em qualquer tamanho de tela.

- `0 - Pose Original.svg`: palco principal e destaque hero.
- `1 - Pose Aqui.svg`: chamada da data e dos ingressos.
- `2 - Pose Força.svg`: seção de atrações.
- `3 - Pose Luta.svg`: programação competitiva.
- `4 - Pose Ok.svg`: experiências e área de expositores.
- `5 - Pose Convidando.svg`: chamada para novos patrocinadores.

Os arquivos `mascot-original.svg` e `mascot-invite.svg` são aliases mantidos para compatibilidade com referências antigas.

Quando novas poses forem criadas, adicione o SVG aqui e use classes próprias para controlar tamanho, posição e rotação sem alterar a arte original.
